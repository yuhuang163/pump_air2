使用方式1:
./jpg2jpg.sh 待转换目录文件 要转换成的YUV420格式(YUV444/YUV422/YUV420)
例如：  ./jpg2jpg.sh ./jpeg/ YUV420


使用方式2：
参数1：alpha使用哪种方式。a4或者a8
参数2：1表示使用rle
参数3：99表示压缩质量，99表示损失最小的压缩。范围：0到99
参数4: 默认的压缩模式， 420或者422或者444
参数5：要转换的文件夹
./png2baj.sh a8 1 99 444 problem_png/

【注意】
YUV420/YUV444 的最大解码宽度为 336
YUV422 的最大解码宽度为 512
